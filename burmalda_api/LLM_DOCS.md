# Бурмалда Translate — LLM-документация для Tool Calling

## Описание сервиса

API для перевода русского текста на **муринский язык (бурмалда)** — мемный язык,
где существительные заменяются на формы с окончаниями `-ость/-ность`,
добавляются приставки `бурмал-/бурмалд-`, а глаголы и служебные слова остаются
без изменений.

**Базовый URL:** `http://localhost:8000`

---

## API Endpoints

### POST `/translate`

Перевести текст с русского на муринский язык.

**Request:**
```json
{
  "text": "Привет дорогой мой друг, как дела с твоим котом?",
  "hard_mode": true
}
```

**Response:**
```json
{
  "original": "Привет дорогой мой друг, как дела с твоим котом?",
  "translated": "Привет дорогой мок друн, как дела с твоей котостью?",
  "hard_mode": true
}
```

**Параметры:**
- `text` (string, обязательный) — текст на русском (1–10000 символов)
- `hard_mode` (bool, опционально, по умолч. `true`) — жёсткий режим переводит больше существительных

### POST `/translate/batch`

Пакетный перевод нескольких текстов.

### GET `/rules`

Получить список правил и примеров перевода.

### GET `/health`

Проверка работоспособности.

## Полные правила перевода

### 1. Словарь исключений (более 200 слов)

Эти слова имеют жёстко заданный перевод, не подчиняющийся общим правилам.

| Категория | Примеры |
|---|---|
| **Местоимения** | я→ч, меня→менч, мне→мье, мой→мок, моя→моч, моё→моё, мы→мч, нас→насч, нам→намч, наш→нашч, наша→нашча |
| **Вопросительные** | кто→кьо, то→ьо, что→чьо, это→эьо |
| **Семья** | друг→друн(а/у/ом), сын→сыр(а/у/ом), жена→жинка(у/е), папа→батч, отец→отчовство, дядя→дядность, учительница→учиха |
| **Дед/прадед** | дед→дод(а/у/ом/ы), прадед→прадод, прапрадед→прапрадод (приставки сохраняются) |
| **Кот/кошка** | кот→котость, кота→котости, коту→котости, котом→котостью, коты→котости, котов→котостей, кошка→кошкость |
| **Школа** | школа→школость, школу→школость, школе→школости, школы→школости, школьник→школьникость |
| **Приставка бурмалд-** | телефон→бурмалдфон, заяц→бурмалдаяц, птички→бурмалдички, перекресток→бурмалкресток |
| **Прилагательные → сущ.** | сладкий→сладость, приятный→приятность, вкусный→вкусность |
| **Наречия на -о** | сладко→сладостно, приятно→приятностно, вкусно→вкусностно (суффикс -стно) |
| **Неизменяемые** | Бурмалда, Мурино, село Молочное, Эпштейн, чекушка, ведь, вопреки, даже, практически, смотря, шел, сели |
| **Глаголы-исключения** | было, находимся, переночевав, летает, помню, явилась, отдана |
| **Прочие** | общага→общагость, этаж→этажность, деньги→деньгость, мем→мемность, меллстрой→меллстройность, туман→фог |

### 2. Служебные слова (НЕ переводятся)

Предлоги, союзы, частицы, местоимения, числительные:

```
и, а, но, или, в, на, с, к, по, за, от, до, для, про, без,
очень, уже, ещё, только, просто, когда, если,
он, она, оно, они, его, её, ему, ей,
один, два, три, четыре, пять,
блин, ладно, нет, да
```

### 3. Глаголы (НЕ переводятся)

Любые формы: инфинитивы, личные формы, прошедшее время,
возвратные глаголы. Проверка по словарю ~250 глаголов + паттерны окончаний.

### 4. Причастия и деепричастия (НЕ переводятся)

Причастия: `отдана, сделано, написан, сделанный, разукрашенные, сказавший`
Деепричастия: `переночевав, сделав, увидев, вернувшись`

### 5. Модели перевода существительных

Если слово не попало в словарь, не глагол и не служебное —
применяются модели по окончаниям (в порядке приоритета):

#### 5.1 -енье/-ение → -енность
```
мгновенье/мгновение → мгновенность
творенье/творение → творенность
страдание/страданье → страданность/страданьесть
```

#### 5.2 -мя → -еность
```
время → временость
имя → именость
пламя → пламеность
знамени → знаменности
```

#### 5.3 -ица/-ице → -очность/-очности
```
гостиница → гостиночность
больница → больночность
песочница → песочночность
```

#### 5.4 -ция → -чность
```
плантация → плантачность
станция → стачность
акция → акчность
реакция → реакчность
```

#### 5.5 дорога/голова (чередование согласных)
```
дорога → дорожность
голова → головность
```

#### 5.6 машина → машинность (слова на -ина)
```
машина → машинность
картина → картинность
долина → долинность
корзина → корзинность
```

#### 5.7 наклейка → наклеичность (слова на -ейка)
```
наклейка → наклеичность
линейка → линеичность
скамейка → скамеичность
```

#### 5.8 -ов (родительный мн.ч.) → -ности
```
светодиодов → светодиодности
проводов → проводности
```

#### 5.9 -ами/-ями (творительный мн.ч.) → -ностями
```
цветами → цветностями
ключами → ключностями
```

#### 5.10 -ник → -ность
```
защитник → защитность
художник → художность
учебник → учебность
```

#### 5.11 Мягкие существительные типа "поле"
```
поле → полесть
полю → полести
полем → полестью
море → моресть
```

#### 5.12 Падежная модель для слов на -у
```
к агенту → к агентности
к директору → к директорности
в машину → в машинность
на сторону → на сторонность
```

#### 5.13 Падежная модель после предлогов
```
от экватора → от экваторности
без сахара → без сахарности
до вечера → до вечерности
```

#### 5.14 Дефолтное окончание -ость/-ность
```
Если ни одна модель не подошла:
- окончание на -а: → -ость (школа → школость)
- окончание на -я: → -ность (линия → линийность)
- окончание на -о: → -ость (окно → окность)
- окончание на ч/щ/ж/ш/ц: → +ность (мяч → мячность)
- твёрдая основа: → +ость (стол → столость)
```

### 6. Приставка бурмал-/бурмалд-

Добавляется к избранным существительным из списка:
```
дом, город, лес, магазин, компьютер, ноутбук,
интернет, чат, переводчик, стол, окно
```

Правило выбора приставки:
- слово начинается с гласной → `бурмалд-` (окно → бурмалдокно)
- слово начинается с п/т/д → `бурмалд-`
- иначе → `бурмал-`

### 7. Согласование (Agreement)

Когда слово становится на `-ость/-ность`, прилагательные и
притяжательные местоимения перед ним согласуются по женскому роду:

```
с твоим котом → с твоей котостью
с любым котом → с любой котостью
с моим котом → с моей котостью
сладким чаем → сладкой чайностью
```

| Меллстрой бурмалдит под зонтом. | Меллстройность бурмалдит под зонтом. |

| Они бежали по полю за мячом. | Они бежали по полести за мячностью. |

## Tool Calling (для LLM)

Ниже — описание функции для использования в OpenAI Function Calling / Anthropic Tool Use.

### `translate_burmalda`

Перевести русский текст на муринский язык (бурмалда).

```json
{
  "name": "translate_burmalda",
  "description": "Переводит русский текст на муринский язык (бурмалда). "
                 "Мемный язык: существительные получают окончания -ость/-ность "
                 "или приставку бурмал-/бурмалд-, глаголы не меняются.",
  "parameters": {
    "type": "object",
    "properties": {
      "text": {
        "type": "string",
        "description": "Исходный текст на русском языке"
      },
      "hard_mode": {
        "type": "boolean",
        "description": "Жёсткий режим: переводить больше существительных",
        "default": true
      }
    },
    "required": ["text"]
  }
}
```

### Prompt для LLM (если нет доступа к API)

Если API недоступен, LLM может переводить самостоятельно по этим правилам:

```
Ты — переводчик на муринский язык (бурмалда). Твоя задача — заменить
русские существительные на формы с -ость/-ность, добавить приставки
бурмал-/бурмалд- к избранным словам, оставив глаголы и служебные слова
без изменений.

Правила (в порядке приоритета):
1. Словарь исключений (см. таблицу выше) — применяй всегда
2. Глаголы, причастия, деепричастия — НЕ меняй
3. Служебные слова (предлоги, союзы, частицы, числительные) — НЕ меняй
4. Слова на -енье/-ение → замени на -енность
5. Слова на -ица/-ице → замени на -очность/-очности
6. Слова на -ция → замени на -чность
7. Остальные существительные → добавь -ость/-ность
8. Согласуй прилагательные и местоимения перед -ость/-ность словами

Не меняй:
- Имена собственные (Бурмалда, Мурино, Эпштейн)
- Слова, которые уже выглядят как бурмалда
- Слова из неизменяемого списка
```
