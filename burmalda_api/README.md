# Бурмалда Translate API

Мемный переводчик с **русского на муринский язык (бурмалда)**.  
FastAPI-сервис, который можно запустить локально, дёргать через API, интегрировать с нейросетями (OpenAI Function Calling, Anthropic Tool Use) или загрузить в LLM как документацию для самостоятельного перевода.

Правила: словарь исключений + приставки `бурмал-/бурмалд-` + окончания `-ость/-ность` + защита глаголов и служебных слов.

---

## Быстрый запуск

```bash
pip install -r requirements.txt
python main.py
# → http://localhost:8000
# Swagger: http://localhost:8000/docs
```

## API

| Метод | Эндпоинт | Описание |
|--------|----------|----------|
| `GET` | `/` | Инфо о сервисе |
| `GET` | `/health` | Проверка |
| `POST` | `/translate` | Перевести текст |
| `POST` | `/translate/batch` | Пакетный перевод (до 100 текстов) |
| `GET` | `/rules` | Правила и примеры |

### Пример запроса

```bash
curl -X POST http://localhost:8000/translate \
  -H "Content-Type: application/json" \
  -d '{"text": "Мой сын пошел в школу с новым телефоном."}'
```

```json
{
  "original": "Мой сын пошел в школу с новым телефоном.",
  "translated": "Мок сыр пошел в школость с новым бурмалдфоном.",
  "hard_mode": true
}
```

### Python

```python
import requests

resp = requests.post("http://localhost:8000/translate", json={
    "text": "Привет дорогой мой друг, как дела с твоим котом?",
    "hard_mode": True
})
print(resp.json()["translated"])
# → Привет дорогой мок друн, как дела с твоей котостью?
```

## Интеграция с нейросетями

### OpenAI Function Calling

```json
{
  "type": "function",
  "function": {
    "name": "translate_burmalda",
    "description": "Переводит русский текст на муринский язык (бурмалда)",
    "parameters": {
      "type": "object",
      "properties": {
        "text": { "type": "string", "description": "Текст на русском" },
        "hard_mode": { "type": "boolean", "description": "Жёсткий режим", "default": true }
      },
      "required": ["text"]
    }
  }
}
```

### Anthropic Tool Use

```json
{
  "name": "translate_burmalda",
  "description": "Переводит русский текст на муринский язык (бурмалда)",
  "input_schema": {
    "type": "object",
    "properties": {
      "text": { "type": "string" },
      "hard_mode": { "type": "boolean", "default": true }
    },
    "required": ["text"]
  }
}
```

## LLM-документация (для загрузки в нейросеть)

Файл [`LLM_DOCS.md`](LLM_DOCS.md) содержит:

- Полное описание всех правил перевода (словарь, модели, согласование)
- Prompt-шаблон для самостоятельного перевода LLM без API
- 30+ примеров перевода
- JSON-схемы для OpenAI / Anthropic

LLM может использовать эти правила, чтобы:
- переводить слова, которых нет в словаре API
- дорабатывать сложные случаи согласования
- обрабатывать уникальные фразы
